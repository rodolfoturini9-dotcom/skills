# MODELO DE ATESTADOS E DECLARAÇÕES MÉDICAS (v3)

### Objetivo

Fornecer modelos padronizados de atestados e declarações médicas para diferentes finalidades, garantindo clareza, objetividade, proteção de dados e segurança jurídica para o profissional de saúde.

---

# ATESTADO MÉDICO POR DOENÇA

## Modelo

# ORIENTAÇÕES ÉTICO-LEGAIS

- Não expor diagnósticos desnecessários.
- Não detalhar informações clínicas sensíveis.
- Não emitir documentos sem respaldo clínico.
- Não exagerar períodos de afastamento sem justificativa.
- Utilizar linguagem objetiva e institucional.
- O CID deve ser inserido apenas quando:
  - solicitado pelo paciente;
  - necessário documentalmente;
  - permitido eticamente.

---

# REGRAS PARA IA

- Não inventar informações.
- Não inferir diagnósticos ausentes.
- Não adicionar explicações extras.
- Omitir informações não fornecidas.
- Linguagem sempre técnica, objetiva e pronta para impressão/prontuário.
